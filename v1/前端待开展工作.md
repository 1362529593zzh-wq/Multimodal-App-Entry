## 配置中心联调收口清单

在进入工作台壳子之前，前端只收口下面 4 件事：

1. 列表查询正常
2. 新增 / 编辑正常
3. 启停正常
4. 错误提示和字段校验正常

建议联调顺序：

1. 功能配置
2. 模型服务
3. 功能模型绑定
4. 参数模板

原因：

- 后两页依赖前两页的字典数据
- 可以先把单表 CRUD 收稳，再检查跨表下拉和关联关系

## 本阶段完成标准

- 4 个配置页面都能实际打开和操作
- 不需要为了前端联调去临时改后端字段名
- 字段校验错误能显示到对应表单项
- JSON 字段在前端能校验合法性并正常提交

## 联调完成后的第一目标

联调收口之后，前端不要先去做统计中心或中间件接入，直接进入：

- 工作台路由页
- 左侧导航
- 中间消息流区域
- 底部输入框
- 功能条
- 参数快捷入口

也就是先做工作台壳子，再配合后端最小会话 / 消息 / 任务骨架。
